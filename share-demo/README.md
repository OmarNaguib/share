# Share demo: a static gallery on GitHub Pages

A small neutral topic that shows what `share publish` makes: the same gallery and viewer as the live share server, as plain files. Tap a picture, then swipe; Back closes it.

- **01-sunrise**: a sunrise gradient, to show a plain picture with a caption from the README.
- **02-sea**: a sea gradient.
- **weekly-plan**: a made-up card. The before/after pair lines up, so it opens as a slider. The light/dark pair is a variant, so it opens side by side.
